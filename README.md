## Writing & Research

* [Claude](https://claude.ai) – Ideal for long document analysis, fast summaries, and writing without tone issues.
* [DeepSeek](https://chat.deepseek.com) – High-powered open reasoning model for technical tasks and logic.
* [NotebookLM](https://notebooklm.google.com) – Upload PDFs or notes and get a hyper-targeted notebook assistant and custom audio summaries.
* [Perplexity](https://perplexity.ai) – Search engine replacement with direct source citations.
* [Zotero](https://www.zotero.org/) – Free reference manager with open-source plugins for automated PDF indexing and research assistance.

## 🖥️ Run AI Locally (100% Offline & Private)

* [Jan](https://jan.ai) – Open-source alternative to ChatGPT that runs fully on your local hardware.
* [LM Studio](https://lmstudio.ai) – A desktop UI for discovering and running GGUF local models without touching a terminal.
* [Ollama](https://ollama.com) – The easiest CLI tool to download and run models like Llama, Mistral, or Qwen locally.
* [Pinokio](https://pinokio.computer) – Browser that lets you install and run complex open-source AI scripts with one click.

## 💻 Coding & Dev

* [Cursor](https://cursor.com) – VS Code fork with fast inline AI edits and codebase-wide indexing.
* [Hugging Face Spaces](https://huggingface.co/spaces) – Free hosting and live demos for thousands of community-built AI apps.
* [OpenCode Interpreter](https://github.com/OpenCodeInterpreter/OpenCodeInterpreter) – Open-source coding system designed to generate, execute, and refine code locally.
* [Vercel v0](https://v0.dev) – Generates UI components using React and Tailwind CSS directly from plain text prompts (Free daily credits).

## 🎨 Image & Design

* [Fooocus](https://github.com/lllyasviel/Fooocus) – Streamlined local SDXL image generator that requires zero technical setup.
* [Ideogram](https://ideogram.ai) – Excellent free daily credits for generating images with precise embedded text.
* [Krita + Generative AI](https://github.com/Acly/krita-ai-diffusion) – Completely free local image generation plugin integrated inside the open-source Krita art program.
* [Vectorizer.ai](https://vectorizer.ai) – Converts bitmapped images (PNG/JPG) into scalable vector graphics (SVG).

## 🎙️ Audio & Music

* [Audacity + OpenVINO Plugins](https://www.audacityteam.org/) – Run local noise suppression, music separation, and transcription inside Audacity for free.
* [MusicGen (Hugging Face)](https://huggingface.co/spaces/facebook/MusicGen) – Meta's open-source music generation tool hosted free on Hugging Face.
* [Suno](https://suno.com) – Generate complete songs (vocals and instrumentation) from text prompts (Daily free credits).
* [WhisperX](https://github.com/m-bain/whisperX) – Fast offline speech-to-text with word-level timestamps and speaker diarization.

## 📹 Video

* [AnimateDiff](https://github.com/guoyww/AnimateDiff) – Open-source framework for animating Stable Diffusion text-to-image models.
* [CapCut Web](https://www.capcut.com) – Free suite of AI auto-captioning, background removal, and video editing tools.
* [Clipchamp](https://clipchamp.com) – Microsoft's free browser-based video editor featuring AI text-to-speech, auto-captions, and smart re-framing.
* [Luma Dream Machine](https://lumalabs.ai/dream-machine) – High-quality text-to-video and image-to-video generation (Free tier).

## 📊 Productivity & Data

* [Excalidraw AI](https://excalidraw.com) – Infinite canvas tool that converts rough hand-drawn sketches into structured diagrams.
* [Fabric](https://github.com/danielmiessler/fabric) – Open-source prompt framework designed to collect, organize, and apply AI prompts across daily tasks.
* [Tableau Public](https://public.tableau.com) – Free platform to visualize and analyze datasets.
